# Money Life Coach

A shareable Cola skill for turning financial records and life context into personalized, actionable guidance.

## What it does

The skill accepts financial data in Excel, CSV, screenshots, app exports, or plain language. It combines spending patterns with four questions about the person's vision, tension, income structure, and resilience before producing a diagnosis and action plan.

It is grounded in Kinder Life Planning, the EVOKE model, and CFPB financial wellness dimensions.

## Install locally

Copy `SKILL.md` into:

```text
~/.cola/resources/skills/money-life-coach/SKILL.md
```

## Scope

This is a coaching and analysis workflow, not an investment-advisory tool. It does not recommend financial products or moralize about spending. Advice should reference the person's actual data and stated goals.
